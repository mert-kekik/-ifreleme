# 🕵️‍♂️ Gizli Mesaj Şifreleyici (Crypto App)

Bu proje, metin tabanlı mesajları tamamen tarayıcı üzerinde, çevrimdışı (offline) olarak şifrelemeye ve çözmeye yarayan tek sayfalık bir web uygulamasıdır. Gelişmiş AES şifreleme standardı kullanılarak oluşturulmuştur.

## 🚀 Özellikler
* **Güçlü Şifreleme:** CryptoJS kütüphanesi ve AES algoritması ile yüksek güvenlikli metin şifreleme.
* **Sunucusuz Mimari:** Hiçbir veri veritabanına veya sunucuya gönderilmez. Tüm işlemler anlık olarak kullanıcının tarayıcısında gerçekleşir.
* **Kullanıcı Dostu Arayüz:** Modern "Dark Mode" (Karanlık Tema) tasarımı ve mobil uyumlu (Responsive) yapı.
* **Pratik Kullanım:** Şifrelenen mesajı tek tıkla panoya kopyalama özelliği.

## 🛠️ Kullanılan Teknolojiler
* HTML5
* CSS3 (Flexbox & Responsive Design)
* JavaScript (Vanilla JS)
* [CryptoJS](https://cryptojs.gitbook.io/docs/) (Şifreleme Algoritması)

## 📱 Nasıl Kullanılır?
1. Şifrelemek istediğiniz metni "Mesaj" kutusuna girin.
2. Sadece alıcının bileceği gizli bir "Şifre" belirleyin.
3. "Şifrele" butonuna basın ve ortaya çıkan anlamsız metni kopyalayıp istediğiniz platformdan (WhatsApp, Mail, SMS) alıcıya gönderin.
4. Mesajı alan kişi, bu siteye girip şifreli metni ve anlaştığınız gizli şifreyi yazarak "Çöz" butonuna bastığında orijinal mesaja ulaşacaktır.
